# Christmas Overlay (Fabric 1.21.11, client only)

15 butterfly-knife skins with hand tricks (main hand or off hand), Christmas mining overlay + particles,
galaxy night sky, vanilla-style hearts/hunger, camera zoom-out, item size, visual swing speed.
Works with Mod Menu (Configure button).

Keys (change in Options > Controls, or in the menu's Keys tab):
- **J** open the settings menu
- **G** hold to do knife tricks (or turn on "Auto tricks")

Build: push to GitHub, Actions builds the jar (Actions > latest run > Artifacts). Put the jar in `mods`.
